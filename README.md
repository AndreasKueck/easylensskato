Estas prezentata traduko Esperanten de la origine germanlingva [prompto](https://github.com/AndreasKueck/easylensskato/blob/main/prompto.md), per kiu Snapchat-lenso "[Skato](https://www.snapchat.com/lens/53639fadb45647bfb25171bd0f94b4e5)" estis kreita per apo Easy Lens. La lenso ebligas al uzanto ludi [skaton](https://eo.wikipedia.org/wiki/Skato) per smartfono ene de apo Snapchat.
